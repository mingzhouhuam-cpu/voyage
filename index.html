💡 如何获取 Supabase 免费云库（2分钟极简教程） 点击展开/折叠 ▼

1. 打开并登录免费云库 supabase.com（支持 GitHub 或 Google 账号一键登录，永久免费）。

2. 点击 New Project 创建一个项目（名称例如 voyage-finance，数据库密码自定保存即可）。

3. 进入左侧导航菜单 SQL Editor，点击 New Query，把下方代码粘贴进去，点击右下角绿色 Run 即可：

create table if not exists finance_store (
  id text primary key,
  data jsonb,
  updated_at timestamp with time zone default now()
);
alter table finance_store enable row level security;
create policy "Allow public access" on finance_store for all using (true) with check (true);
alter publication supabase_realtime add table finance_store;

4. 进入左侧 Project Settings -> API 或 Data API，把 Project URL 和 Publishable key 复制并填入下方输入框中，点击【保存并连接】！在其他电脑上打开网页填入相同的配置即可实现全自动双向实时同步。

默认使用 voyage_learning_2026。所有电脑只需保持该标识相同，即可共享同一账本。
